Baluster Spacing: The "4-Inch Rule"

The most common inspection failure for DIY decks is incorrect baluster spacing.

What is Code?

IRC Code R312.1.3

"Required guards shall not have openings from the walking surface to the required guard height which allow passage of a sphere 4 inches in diameter."

How to Install Evenly

The amateur way is to start at one end with a 4-inch block and keep going. The problem? When you get to the end of the rail, you might have a tiny 1-inch gap left over. It looks terrible.

The Pro Way (Math):

  1. Add the width of one baluster to your desired gap (e.g., 1.5" + 3.5" = 5").
  2. Divide the total rail length by that number (e.g., 68" / 5" = 13.6).
  3. Round UP to the next whole number (14). This is your number of spaces.
  4. Divide rail length by the number of spaces to get the On-Center measurement.

Center-Mark Method

Instead of measuring "gap-spindle-gap," professional deck builders mark the centers . It is faster and more accurate. Use the "Start First Mark At" number from our calculator to mark the center of the first baluster, then just add the "On-Center" distance for each subsequent one.
