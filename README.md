# RenoCalcHub

![Project Screenshot](./assets/screenshot.png)

## 📖 Overview
RenoCalcHub is a lightweight, lightning-fast static web application featuring a collection of over 27 practical construction and renovation calculators. Built from the ground up to solve real-world calculation problems efficiently, it provides a seamless user experience without relying on heavy CMS platforms or bloated frameworks.

## 🚀 Live Demo
**Live Application:** [renocalchub.com](https://renocalchub.com)

## 💻 Tech Stack
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript, Tailwind CSS
*   **Backend & Automation:** Python (for automated content architecture and page generation)
*   **Search Engine:** Fuse.js (Fast, lightweight fuzzy-search)

## ✨ Main Features
*   **27+ Dynamic Calculators:** Comprehensive tools for construction and renovation planning.
*   **Lightning-Fast Search:** Implements Fuse.js for highly responsive fuzzy search capabilities.
*   **Technical SEO Engine:** Highly optimized structure featuring JSON-LD structured data and OpenGraph integration.
*   **Automation Pipeline:** Utilizes Python scripts for streamlined page and content generation.
*   **Responsive UI:** Fully responsive and mobile-friendly design for accessibility on all devices.

## 📦 Dependencies
*   `tailwindcss`
*   `fuse.js`

## 🛠️ How to Run Locally

To get a local copy up and running, follow these simple steps in your terminal:

```bash
# Clone the repository
git clone [https://github.com/Md-Rifat-Al-Faisal/RenoCalcHub.git](https://github.com/Md-Rifat-Al-Faisal/RenoCalcHub.git)

# Navigate into the project directory
cd RenoCalcHub

# Install dependencies (for Tailwind CSS compilation)
npm install

# Start a local development server
npm run start
